# DOP.Workout

Deck of Pain — the Jailhouse Strong card-deck workout.

## Deploy (GitHub Pages)
1. Replace the repo contents with the files in this folder (delete the old `assets/` folder).
2. Commit and push to `main`.
3. Settings → Pages → Deploy from branch `main`, folder `/ (root)`.

## Files
- `index.html` — the whole app, self-contained
- `sw.js` — offline support
- `manifest.webmanifest` + `icons/` — install to home screen
